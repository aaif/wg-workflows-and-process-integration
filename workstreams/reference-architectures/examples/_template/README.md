# _template — start a new use case here

Status: Scaffolding (not a worked example)

This folder is a **copy-paste starting point**, not an exemplar. Use it to run a new use
case through WERA and produce a full solution.

## Steps

1. Copy this folder to `examples/<your-usecase>/` (a short, kebab-case name).
2. Delete this `README.md` from the copy — the agent will generate the real at-a-glance
   `README.md` as part of the solution.
3. Fill in [`use-case.md`](use-case.md) — the business problem, exactly as a stakeholder
   might hand it over. Replace `<Use-case name>`, write every section, and delete the
   italic hint under each heading as you go. This is the only file you write by hand.
4. Follow [../HOW-TO-RUN.md](../HOW-TO-RUN.md): paste the generic prompt into your coding
   agent, with `<FOLDER>` set to `<your-usecase>`.

[`SOLUTION-FILES.md`](SOLUTION-FILES.md) lists exactly what a full solution contains and
what "done" means. Keep it in the copy as a checklist, or delete it once the solution is
complete.
