# [Report] Workflows & Process Integration – July 2026
**Working Group:** WG Workflows & Process Integration

**Reporting period:** July 2026

**Chair(s):** Yaron Schneider (Diagrid) & Adam Seligman (Workato)

**Date submitted:** 2026-07-30

---

## Summary

All three work streams (Reference Architectures, Critical Use Cases, Taxonomy) produced concrete, drafted artifacts this month. The group spent July converging on shared frameworks it judged were prerequisites for a meaningful vote. Reference Architectures built and demonstrated a specification-driven design flow (use case → machine-readable YAML spec → generated diagrams and docs) end-to-end on two use cases. Critical Use Cases catalogued and categorized 89 use cases against a shortlist of under 10 reusable patterns. Taxonomy's cross-WG unified term set is drafted and headed to PR. The common thread across all three: work is drafted and review-ready but still sitting outside the official repo, with next steps presenting to the wider group any votable artifacts.

## Progress Against Objectives

- **Reference Architectures** — *Leads: Mario, Zayne*
  - Two workstream syncs held (14 July, 30 July); 6–7 regular attendees each session
  - Defined 7 execution profiles (1 = fully deterministic → 7 = fully agentic) and a proposed "least agentic default" recommendation principle, currently open for group discussion
  - Drafted 6 charter-derived archetypes (e.g. bounded automation, gated operation) — still pending validation
  - Built and demoed a specification-driven design flow end-to-end on 2 use cases (invoice processing, autonomous maintenance run), each generated in a default (profile 3) and more-agentic (profile 4) variant
  - Two PRs open against the workflow repo (foundation/pattern-catalog PR, specification-driven PR) — **not yet merged**. Decision reached this week: merge the foundation PR first, then layer the specification-driven PR on top

- **Critical Use Cases** — *Leads: Kevin Ng (Telus), Jodee Varney (Cisco); contributor: Rocky Zhang (SAP)*
  - 89 use cases catalogued and categorized against primitives (trigger, human-in-the-loop pattern, agent count, coordination, workflow pattern)
  - Pattern list finalized at under 10 patterns, including a newly-added "autonomous convergence loop" pattern
  - All still tracked in a working gist, not yet in the official repo — migrating it to a PR has been a stated next step across two consecutive syncs (6 July, 13 July) and still hasn't happened

- **Taxonomy** — *Lead: Gala (also co-chair, cross-WG Taxonomy & Landscaping WS)*
  - Unified cross-WG term set (e.g. "agent") drafted; PR to formalize it is prepared but not yet opened
  - Jodee's 89-use-case primitive categorization is doing double duty as a taxonomy input, being used to pressure-test alignment with the Reference Architecture workstream's vocabulary

## Blockers and Risks

- **Cross-WG taxonomy overlap (carried over from June).** Different WGs still risk independently defining overlapping terms.
  - *Mitigation:* actively de-risking — Gala's cross-WG unified term-set PR is drafted, and the RA workstream has already decided to hold off on locking its own machine-readable short codes until that PR lands, so work isn't being built on terms that later get overridden.
- **Reference Architecture and Critical Use Cases primitives may diverge if not reconciled before either publishes.** RA's archetypes/execution profiles and Use Cases' 89-item primitive categorization were built largely independently and haven't been cross-validated against each other yet.
  - *Mitigation:* both workstreams have flagged this explicitly and committed to a cross-check — Sumanth reviewing RA parameters against taxonomy terms, and Use Cases scenarios to be run through RA's wizard-style walkthrough as a validation test.
