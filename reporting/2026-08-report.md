## Summary

Taxonomy delivered the working group's first shipped artifact this month: the Phase One Core Terms draft was reviewed and formally voted through at the August plenary, making Workflows & Process Integration the first AAIF working group to deliver an actual asset. Reference Architectures is close behind its own 29 August charter deadline with architecture principles and a contributing guide are merged to main, the first reference architecture ("human-approved operation") is merged, and the second ("bounded autonomous remediation") is reviewed and ready to merge. Deliverable scope now locked at 2 reference architectures plus taxonomy, principles, and a contributing guide. Critical Use Cases is the work stream still finding its footing: its repo migration finally opened as PR #33, but reviewing real use cases against the newly-voted "activity" terminology immediately surfaced friction and a documentation gap between the WG's own running notes and the merged taxonomy. That deliverable now waits on a terminology-alignment pass before it can go to a vote.

## Progress Against Objectives

- **Reference Architectures** — *Leads: Mario, Zayne*
  - Two syncs held (11 Aug: 7 attendees, 25 Aug: 6 attendees)
  - **Merged to main:** architecture principles document and contributing guide (PR #27)
  - **Merged:** first reference architecture, "human-approved operation" (agent proposes → human approves → controlled executor acts)
  - **Ready to merge:** second reference architecture, "bounded autonomous remediation" (PR #26 — agent runs multiple operations internally, escalating only on budget/limit breach); reviewed as of 25 Aug but not yet merged
  - Deliverable scope for the 29 August charter deadline is now locked: 2 reference architectures + taxonomy + principles + contributing guide (operations layer and UX explicitly out of scope) — replacing the more open-ended "2–3 architectures" framing from two weeks earlier once a third draft failed to materialize in time
  - Defined a 4-outcome validation method — validated / partial / candidate / no fit — that checks architectural fit only (same job, same boundaries) against the use case catalog, with no implementation detail. "Bounded autonomous remediation" is already validated by the use case it was built from; "human-approved operation" is marked *candidate* pending validation against 1–2 more inventory use cases
  - Grouped use cases into 3 cohorts to prioritize what gets built next: human-approved operation (covered), bounded autonomous remediation (partially — its parallel variant still has no topology), and exception detection & escalation (no architecture yet — next likely candidate)
  - Parked two oversized PRs until after the deliverable, a primitives/topologies PR (#29) and a 100+-file experimental PR. We set a standing rule capping future PRs at ~10 files.
  - **At risk:** as of the 25 Aug sync, 4 days before the 29 August target, PR #26 is drafted but unmerged, the validation record update hasn't started, and the validation guide hasn't been opened as a draft PR yet

- **Critical Use Cases** — *Leads: Kevin, Jodee*
  - One sync in August (24 Aug, 2 attendees)
  - The repo-migration PR flagged as overdue in the June and July reports is now open as **PR #33** and in active review — progress, though review immediately hit a terminology snag: "activity" (the term Taxonomy just voted through) doesn't read naturally in use case write-ups, where "step"/"action" is the more common phrasing
  - Surfaced a documentation gap: this WG's own Running Notes (phase 1 core terms) have drifted from the current merged taxonomy (`workstreams/taxonomy/terms.md`); Jodee is reaching out to the Taxonomy workstream directly to reconcile
  - Not yet delivered: per the August plenary, the use cases list goes to a vote only after this terminology-alignment pass, will likely happen in 1 - 2 meetings

- **Taxonomy** — *Lead: Sumanth; cross-WG liaison: Gala*
  - **Shipped:** the Phase One Core Terms taxonomy draft was reviewed and voted through at the August plenary: this WG's first delivered deliverable, and the first shipped by any AAIF working group
  - 6 terms accepted so far by the global cross-WG taxonomy team; remaining terms still under debate there, with Sumanth continuing to advocate for an Agentic-AI-specific framing where the global team's default leans toward not redefining existing terms
  - Resolved a naming debate as part of the vote: adopted "activity" over "step"/"workflow step," and restructured definitions so activity is defined first (without referencing workflow) and workflow is defined as a composition of activities — removing a circular-definition problem Filip flagged
  - Explicitly scoped **out**: gate/check/evaluation terminology, which stays with the Security, Observability, and Accuracy & Reliability working groups
  - Immediate follow-on work: propagate the approved terms and replace "execution engine" with "lifecycle" in the RA docs (Mario, reviewed by Sumanth), and reconcile Critical Use Cases' running notes against the merged terms.md (Jodee, Sumanth)

## Blockers and Risks

- **29 August deliverable deadline is tight.** As of the 25 Aug sync, 3 items remain open: merging PR #26, updating the single-agent architecture's validation record, and opening the validation guide as a draft PR.
  - *Mitigation:* all three are small, bounded, already-owned tasks (Mario/Sumanth merging with Yaron; Ivana/Danijel on validation; Mario on the guide) rather than open-ended work, which is why the group still believes the date is reachable.
- **Terminology adoption friction.** The newly-voted "activity" term is awkward in practice for Critical Use Cases, and their own running notes have drifted from the merged taxonomy.
  - *Mitigation:* Jodee is engaging the Taxonomy workstream directly, which has signaled openness to refining terms based on real usage feedback
- **Upstream taxonomy alignment is only partial.** Only 6 of our WG's proposed terms are accepted by the global cross-WG taxonomy team so far; that team's default preference not to redefine existing terms means our Agentic-AI-specific framing still needs active advocacy to land.
  - *Mitigation:* Sumanth continuing direct engagement upstream; no blocking impact on the v1 already shipped by this WG, but later upstream changes could force rework.
- **Large, hard-to-review PRs.** A 100+-file experimental PR and a large primitives/topologies PR (#29) both proved too big to review or explain.
  - *Mitigation:* both parked until after the August deliverable, to be cherry-picked in small pieces; a standing ~10-file cap now applies to future PRs.
